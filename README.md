# S&P 500 Treemap

A demo app built in [Declare](https://github.com/davidtemkin/declarelang), 
showing off a custom layout `TreemapLayout` plus some Declare native pieces: 
- `RadioGroup` for the weight-metric toggle
- the built-in `tip` attribute for hover tooltips, and 
- an expand-to-fullscreen drill-down per sector.

Features:
- Toggle between **Market Cap** and **Employees** as the box-sizing metric.
- Companies are grouped by **Sector** (outer boxes, colored) with each company as a leaf
  box labeled by its ticker `Symbol`.
- Click the expand icon on a sector to zoom into just its companies.
- Hover a company for its Long Name, Market Cap, and Employees.

## Files

- `sp500-treemap.declare` — the app.
- `treemap-layout.declare` — `TreemapLayout` declaration
- `sp500_companies.csv` — the raw source data.
- `prep_data.py` — trims the CSV down to `sp500.json` (symbol, name, sector, marketcap,
  employees only)
- `sp500.json` — generated by `prep_data.py`, already committed; the app fetches this
  directly, no server involved. Regenerate it if `sp500_companies.csv` changes:
  `python3 prep_data.py`.

## Running it

This is a [Declare](https://github.com/davidtemkin/declarelang) app, so it needs the
Declare toolchain to compile/serve:

```bash
# from a checkout of davidtemkin/declarelang
node server/dev.mjs   # dev server with live compilation
# then open http://localhost:<port>/path/to/sp500-treemap.declare
```

Or build a standalone static bundle (no dev server needed to view it after):

```bash
node tools/declarec.mjs path/to/sp500-treemap.declare -o dist
```

## Live demo

`docs/` is a prebuilt static bundle (compiled with `declarec`, ~65KB gzipped) — this repo
is set up to serve it via GitHub Pages ( `main` /`docs`).
No server involved; it's just `index.html`, one JS bundle, and `sp500.json`.

Rebuild `docs/` after editing `sp500-treemap.declare`:

```bash
./build-pages.sh
```

(assumes a sibling checkout of `davidtemkin/declarelang` at `../declarelang`)
